# Bing Wallpaper Viewer

Browse [Bing](https://www.bing.com) daily wallpapers by date.

## Features

- View high-resolution Bing wallpapers by date
- Built with React, TypeScript, and Tailwind CSS

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later)
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```
